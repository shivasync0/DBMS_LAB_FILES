# DBMS Lab Files

This repository contains the Database Management System (DBMS) lab experiments, queries, and documentation.

## Repository Structure

- **Experiment 1**: Introduction to DBMS, basic SQL commands and DDL operations.
- **Experiment 2**: Schema definition, tables, constraints, foreign keys, and DML insertions.
- **Experiment 3**: Data manipulation, multi-table queries, joins, and aggregate functions.
- **Experiment 4**: Complex queries, subqueries, and views.
- **Experiment 5**: Stored procedures, PL/SQL blocks, and functions.
- **Experiment 6**: Database triggers, auditing, and events.

## Prerequisites
- MySQL / Oracle / PostgreSQL / SQL Server
